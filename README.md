### Структура репозитория

Папка docs содержит документы по контрольным точкам. Сейчас там находятся Отчет_MDMTSP_КТ1.docx и Описание_MDMTSP_КТ2.docx.

Папка src содержит исходный код на C++. Здесь развивается вычислительная часть проекта: базовые солверы и инфраструктура для экспериментов.

Папка tests предназначена для тестов. В приоритете проверки корректности валидации решений, подсчёта стоимости и вычисления метрик.

### Запуск

Интерфейс запуска зависит от текущего состояния кода в src и развивается вместе с проектом. Рекомендуемый подход — фиксировать seed для воспроизводимости, задавать единый бюджет времени или итераций для сравнения методов и сохранять результаты запусков в удобном формате (например, CSV или JSON) вместе с параметрами.

### Примечание про LKH

Если используется внешний солвер LKH, исполняемый файл должен быть доступен в PATH или задан через переменную окружения LKH_EXECUTABLE. В таком режиме LKH подключается как зависимость среды, а код репозитория использует его через обёртку.

### Принципы воспроизводимости

Для корректного сравнения методов фиксируется seed во всех рандомизированных процедурах, используется единый бюджет времени или итераций, а конфигурации запусков сохраняются вместе с результатами. Изменения в алгоритмах фиксируются коммитами, чтобы можно было однозначно сопоставлять результаты с версией кода.
