MDMTSP TERMINAL COMMANDS
========================

Переход в корень репозитория

cd /Users/mrggrm/Documents/GitHub/MDMTSP-HSE-RESEARCH


Создание виртуального окружения Python

python3 -m venv .venv


Активация виртуального окружения

source .venv/bin/activate


Установка Python-зависимостей

python -m pip install -r requirements.txt


Выдача прав на shell-скрипты

chmod +x scripts/rebuild_macos.sh
chmod +x scripts/ci_sanity.sh


Быстрая инкрементальная сборка на macOS

./scripts/rebuild_macos.sh


Чистая пересборка на macOS

./scripts/rebuild_macos.sh --fresh


Чистая пересборка и запуск C++ тестов

./scripts/rebuild_macos.sh --fresh --tests


Debug-сборка

./scripts/rebuild_macos.sh --build-type Debug


Сборка только target mdmtsp

./scripts/rebuild_macos.sh --target mdmtsp


Ручная конфигурация CMake

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release


Ручная сборка CMake

cmake --build build -j


Запуск всех C++ тестов через CTest

ctest --test-dir build --output-on-failure


Запуск одного C++ теста через CTest

ctest --test-dir build --output-on-failure -R test_objective


Запуск всех Python тестов

python -m unittest discover -s tests -p "test_*.py"


Запуск одного Python тестового файла

python tests/test_check_instances.py


Полный repository sanity-check

bash scripts/ci_sanity.sh


Проверка JSON-конфигов в configs/

find configs -name "*.json" -print0 | while IFS= read -r -d '' f; do python -m json.tool "$f" > /dev/null || exit 1; done


Проверка JSON-инстансов в instances/

find instances -name "*.json" -print0 | while IFS= read -r -d '' f; do python -m json.tool "$f" > /dev/null || exit 1; done


Генерация исследовательского набора инстансов

python scripts/generate_research_instances.py


Просмотр справки генератора инстансов

python scripts/generate_research_instances.py --help


Валидация всех research-инстансов

python scripts/check_instances.py instances/research


Валидация всех инстансов с отчётами CSV и JSONL

python scripts/check_instances.py instances --report-csv results/reports/instance_check.csv --report-jsonl results/reports/instance_check.jsonl


Жёсткая валидация инстансов с падением и на warnings

python scripts/check_instances.py instances/research --fail-on-warning


Создание нового алгоритма через Python-скрипт

python scripts/add_algorithm.py cheapest_insertion


Создание нового алгоритма с принудительной перезаписью шаблона

python scripts/add_algorithm.py cheapest_insertion --force


Просмотр справки скрипта добавления алгоритма

python scripts/add_algorithm.py --help


Запуск основного рабочего suite до 25000 клиентов

python scripts/run_suite.py --config configs/suites/research_until_25000.json --executable build/bin/mdmtsp


Запуск полного research suite

python scripts/run_suite.py --config configs/suites/research_all.json --executable build/bin/mdmtsp


Запуск suite только для одной группы

python scripts/run_suite.py --config configs/suites/research_group_03.json --executable build/bin/mdmtsp


Запуск suite только с одним алгоритмом поверх конфига

python scripts/run_suite.py --config configs/suites/research_group_03.json --executable build/bin/mdmtsp --algorithms nearest_neighbour


Запуск suite с несколькими алгоритмами поверх конфига

python scripts/run_suite.py --config configs/suites/research_all.json --executable build/bin/mdmtsp --algorithms nearest_neighbour random_insertion


Просмотр справки основного suite-runner

python scripts/run_suite.py --help


Ручной запуск исполняемого файла solver-а

./build/bin/mdmtsp --help


Агрегация всех результатов из results/runs

python scripts/aggregate_results.py --search-root results/runs


Агрегация результатов из нескольких корней

python scripts/aggregate_results.py --search-root results/runs --search-root archived_runs


Просмотр справки агрегатора

python scripts/aggregate_results.py --help


Построение всех графиков и route-визуализаций по умолчанию

python scripts/plot_results.py


Построение только aggregate plots без route-визуализации решений

python scripts/plot_results.py --no-solution-visualizations


Построение графиков с ограничением на инстансы до 10000 клиентов для solution plots

python scripts/plot_results.py --max-solution-customers 10000


Перерисовка уже существующих route-визуализаций

python scripts/plot_results.py --overwrite


Просмотр справки plot_results.py

python scripts/plot_results.py --help


Экспорт Excel-отчёта по runs и logs

python scripts/export_excel_report.py --runs-root results/runs --logs-root results/logs --output results/reports/research_report.xlsx


Просмотр справки Excel-export скрипта

python scripts/export_excel_report.py --help


Отрисовка одного решения из run JSON

python scripts/visualize_solution.py results/runs/<suite>/<algorithm>/<group>/<instance>/<run_file>.json


Отрисовка одного решения с явным output PNG

python scripts/visualize_solution.py results/runs/<suite>/<algorithm>/<group>/<instance>/<run_file>.json --output results/plots/solution_view.png


Отрисовка одного решения с явным указанием instance JSON

python scripts/visualize_solution.py results/runs/<suite>/<algorithm>/<group>/<instance>/<run_file>.json --instance instances/research/group_03/<instance>.json --output results/plots/solution_view.png


Отрисовка решения с подписями депо

python scripts/visualize_solution.py results/runs/<suite>/<algorithm>/<group>/<instance>/<run_file>.json --annotate-depots --output results/plots/solution_view.png


Просмотр справки visualize_solution.py

python scripts/visualize_solution.py --help
